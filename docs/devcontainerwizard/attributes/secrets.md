# secrets

## Examples

For usage examples, see [secrets presets](../examples/secrets.md).

## Arguments

The following arguments are supported:

| Name | Type | Format | Description | Required | Default |
|------|------|--------|-------------|----------|---------|
| description | string | - | What the secret is for. Shown next to the input when the IDE prompts for its value. | No | - |
| documentationUrl | string | url | Link shown alongside the prompt, pointing at instructions for obtaining the value. | No | - |
